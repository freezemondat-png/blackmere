# BLACKMERE

## AAA Survival Horror Project

Blackmere is a cinematic gothic bio-horror survival horror experience centered around the Scarlet Strain, a living ecosystem of psychological mutation, biological hierarchy, and environmental decay.

The project focuses on:
- atmospheric horror
- survival tension
- ecosystem-driven AI
- cinematic storytelling
- immersive worldbuilding
